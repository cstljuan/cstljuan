## 作品 · Selected work

### [Seams](https://github.com/cstljuan/Seams)

**Where planned grid projects meet.** Seams maps planned electric utility work and surfaces nearby projects that could coordinate outage windows, access, crews, equipment, and logistics.

Built with a team at ShellHacks 2026 for the Sperry Tech GridLock challenge.

[Live site](https://www.seams.design) · [Devpost](https://devpost.com/software/seams) · [Demo video](https://youtu.be/CgoBQCA358g)
